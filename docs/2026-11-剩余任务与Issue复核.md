### 1.2 已实现但仍有已知限制

| ID | 限制 | 说明 |
| --- | --- | --- |
| L-01 | `run_actions` 单步超时是协作式的 | `steps[].timeout_ms` 已接入 linked CTS；不检查取消令牌的 handler 仍可能跑完预算。无法在不改所有 handler 的前提下强制中断同步调用。 |

| L-05 | OCR 对中文小字精度无保证 | 已支持 upscale、bilinear 和坐标回映射；识别率仍取决于系统 OCR 引擎和字体/对比度。 |

| L-07 | 已加入 Job 的进程不能事后 detached | Windows 不支持把进程移出 Job；`lifecycle=detached` 只对新启动进程生效。 |
| L-08 | 帧缓存严格隔离只保证两个客户端 | 单客户端 6 帧 / 16MB；第三个及以上客户端同时刷帧时，全局 8 帧 / 32MB 仍可能淘汰旧帧，但每个客户端最新帧优先保留。 |

## 2. I-01～I-14 静态复核

### I-01 `find_element` 返回过期快照数据（P0）

- 代码：`SnapshotMeta`、`FindQuery.NewSnapshot/Scope`、`outside_snapshot`、`sources[]`、元素 `hwnd` 已实现；`SortMatches` 先按快照根分组再应用 `prefer`。
- 结论：**条件修复**。默认仍跨窗口查询；`outside_snapshot` 提供判别信号，`new_snapshot=true`/`scope=snapshot` 提供一致视图。未在 CCW 上复现 issue 原始场景。

### I-02 坐标点击不报告命中元素 / 误点标签页 ✕（P0，安全）

- 代码：`DescribeAtPoint` 只读命中测试、`hit_element`/`hit_source`、`DestructiveTargetGuard`、UIA Invoke 前回调护栏、15% TabItem 热区、`select_tab`/`close_tab` 已实现；`click_ref` 也补了 `suspect_noop`。
- 结论：**条件修复**。UIA 不可用或自绘控件不暴露关闭热区时仍可能漏拦；非标准 AutomationId 仍是启发式。

### I-03 模态对话框 hwnd 不稳定（P1）

- 代码：`press_keys`/`type_text` 的 `target=app/current_dialog/foreground`、`ResolveCurrentDialog`、owned 前台校验、`E_WINDOW_AMBIGUOUS`、`E_BLOCKED.dialogs[].suggested_target` 已实现。
- 结论：**基本解决**。非 owned 的自定义“对话框”仍需要显式 hwnd，属于方案已声明残留。

### I-04 消息点击静默失效（P1）

- 代码：`focus_before/after`、`focus_changed`、`delivery`、`suspect_noop` 已实现；`click_ref` 也返回 `suspect_noop`。
- 结论：**条件修复**。消息通道无 ACK，只能靠三证提高判别率。

### I-05 双击竞态（P1）

- 代码：所有 `clicks>1` 现在都走逐击执行；每击重新注入、按 `interval_ms/settle_ms` 间隔，默认在检测到新顶层窗口后中止；返回 `clicks_done/aborted/opened_dialog`。
- 结论：**条件修复**。检测与点击之间仍有毫秒级竞态；`abort_on_window_change=false` 时行为与旧版不同，但已逐击解析。

### I-06 缺少表格读取接口（P2）

- 代码：新增 `read_table`；支持 `root_ref/within/name/control_type/automation_id/pid/index/max_rows/row_start/columns/max_cells/include_header`；GridPattern/TablePattern 优先，DataItem 回退；`row_start` 在读取层生效；树回退按全局列锚点对齐；表头为空/重复/少于实际列数时补齐 `colN` 并去重，避免列值被覆盖。
- 结论：**代码层解决**；真实 UIA 表格验收仍待 R-02。

### I-07 表格内剪贴板复制不完整（P2）

- 代码/文档：不新增剪贴板工具；README、技术文档、`ErrorCatalog` 的 `E_VERIFY_FAILED` hint 指向 `read_table`/ValuePattern；状态表不再依赖 `Ctrl+A/C`。
- 结论：**替代修复**。应用自身 `ValuePattern` 截断时仍无法修复。

### I-08 会话中途重置 / 应用生命周期（P1）

- 代码：`lifecycle=session/detached`、`state.json` v2、`clientKey`/`tempProfile`、崩溃后 recovered 登记、连接时按 `clientKey` 自动认领、`get_environment.session.previous_pid/previous_started_at/state_age_ms/input_lease` 已实现。
- 结论：**条件修复**。`detached` 只对新启动进程有效；已入 Job 的进程无法事后脱离；恢复期间二次崩溃已保留 state 清单。

### I-09 截图不支持放大（P3）

- 代码：`capture_screen`/`snapshot` 的 MCP 入口允许 `scale` 0.1–4.0；`PngWriter`、`ScreenCaptureService`、`SnapshotScreenshotOps` 支持超采样；输出超过 40MP 返回 `E_INVALID_ARG`。
- 结论：**解决**。新增 `SnapshotScaleTests` 覆盖 `snapshot` 和 `capture_screen` 的 4x 请求。

### I-10 窗口大于虚拟屏 / 越界读取（P3）

- 代码：`fit=clamp` 使用 DWM 可见边界并回写 placement，返回 `fit_adjusted/requested_bounds/applied_bounds`；`set_display.fit_windows`/`VSP_FIT_MANAGED_WINDOWS` 支持重排时夹取；读类工具默认裁剪并返回 `clipped`；`assert_region`/`wait_for` 新增显式 `clip`。
- 结论：**解决**。应用最小尺寸大于虚拟屏时仍只能依赖读取侧裁剪，属于方案已声明残留。

### I-11 OCR 对中文小字差（P3）

- 代码：`read_screen_text`/`click_text` 支持 `upscale`（0=auto）、坐标回映射；输出 `ocr_source_width/height`、`ocr_scaled_width/height`；默认 bilinear，支持 `VSP_OCR_UPSCALE=nearest`。
- 结论：**条件修复**。识别率仍取决于系统 OCR 引擎，中文小字无保证。

### I-12 前台守卫导致每次点击都要显式 keep_foreground（P3）

- 代码：新增 `lease_input`（acquire/release/renew/status）；`keep_foreground` 租约化；`renew` 保留/更新 exclusive；`exclusive=true` 有 200ms 前台守护；`get_environment.session.input_lease` 暴露当前租约。
- 结论：**代码层解决**；`exclusive` 可能与用户抢前台，默认仍为非独占。

### I-13 `input` 通道移动真实光标、跨调用不保持前台（P1）

- 代码：租约期间 `press_keys`/`gesture`/`click` 不恢复前台；`CursorGuard` 在租约活跃时保持暂停；`force=true` 真正移除对方租约；`exclusive` 前台守护。
- 结论：**条件修复**。真实光标移动无法在用户态消除；虚拟 HID/独立输入桌面不做。

### I-14 缺少批量执行通道（P2）

- 代码：新增 `run_actions`；白名单、只读外层拒绝、整批共享租约、已有租约续期、`dry_run` schema 校验、执行时 ref 归属检查、`steps[].timeout_ms` 协作式单步超时、`gesture` 文档白名单。
- 结论：**代码层解决**。单步超时依赖 handler 协作；`dry_run` 因动态 ref 不做归属预检。

### 3.1 2026-11-27 质量修复复核

静态复核发现的 10 个残余问题已处理：

| 问题 | 处理 |
| --- | --- |
| 被抢占客户端恢复前台未检查其他租约 | `InputRouter` 在仍有活跃租约时只 `DeferRestore`，最后一个租约结束时统一恢复 |
| `_preemptedPrevious` 无 TTL | 待归还目标增加 120s TTL，`PruneExpiredLocked` 统一清理 |
| `ClearAll` 返回值被忽略 | `ClearAll` 返回最早捕获的前台，`ClearBlocked` 负责恢复 |
| `FrameStore` 全局配额淘汰其他客户端基线 | 单客户端 6 帧 / 16MB，全局淘汰保留每个客户端最新 1 帧 |
| `clientKey` 规范化导致旧键不匹配 | 新 key 仍规范化；自动认领同时匹配旧算法的原始/排序 key |
| 旧 state 缺 `StartedAt` 退回进程名匹配 | 缺 `startedAt` 按旧进程已退出处理，继续恢复 |
| `invoke_element(select_text)` 被破坏性护栏阻断 | `select_text` 只选择不触发，不再套用破坏性护栏 |
| `run_actions` 转发图片缺少步骤归属 | 每组转发内容前插入 `[step N] action` 文本标记 |
| 短租约缩短其他客户端的长租约暂停 | `FocusGuard.Pause` 取现有暂停与新租约到期时间的较大值 |
| 非独占 release/renew 停掉其他客户端独占守护 | 仅当 `_exclusiveClientId` 属于当前客户端时才停止 |
