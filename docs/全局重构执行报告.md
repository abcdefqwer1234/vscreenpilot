### 2.7 P4：环境诊断组装

- 新增 `Session/EnvironmentReporter.cs`（366 行）：`get_environment` 的会话/显示/应用/前台/光标/指标组装。
- 通过 `IEnvironmentHost` 注入只读状态与 `Ensure`/`PruneApps`/`OwnDisplay` 三个动作。

### 2.8 P4：客户端上下文与路径策略

### 2.9 P5：工具层（核心完成）

- `ToolDescriptor`/`ToolPolicy`/`ToolRegistry`/`ToolExecutor` 落地；22 个工具、22 条策略。

- **未完成**：`ToolContext`、`Tools/Definitions/*.json`、删除 `SessionManager` 门面、迁移 `ToolCatalogTests` 到 `ToolRegistry`。`ToolResponseWriter` 已落地并用于视图响应。

### 2.10 P7：UIA 单线程宿主（服务级 + 句柄完成）

- 新增 `Automation/Ui/UiaHost.cs`：专用 MTA 线程 + `BlockingCollection` 队列；服务级调用（建树、查找、焦点、文本、值）串行执行。

- 句柄级 `UiaElementHandle.Focus/Invoke/GetText/SetValue/Dispose` 也通过 `InvokeOn` 回到所属代际 worker；带同线程重入保护。
- MSAA 的 FindElements/DoDefaultAction/GetBounds/GetValue/SetValue 已并入同一 worker（`InvokeMsaa`）。
- **未完成**：`ResetUia` 仍是退休入口；`UiaService._sync` 锁仍保留（单 worker 下冗余）；卡死注入/句柄计数压测未做。

## 7. 风险与纪律

| 风险 | 应对 |
|---|---|
| 视图字段漂移 | 先定义视图再改 handler；golden 锁字段顺序；只允许“通过→失败”判回归 |
| 快照锁语义变化 | 继续用 `ElementRefStore.SyncRoot`；组件内不新增第二把 ref 锁 |
| UIA worker 死锁 | 独立提交、卡死注入压测、保留回退点 |
| 删除门面时牵连静态工具 | 与 `_gate`/注册表一起搬，一次性改完并跑全量单测 |
| 宽捕获误吞异常 | 只收窄类型或补日志，不改控制流 |
