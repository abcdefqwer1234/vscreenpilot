## 3. 复验过程中发现的新问题

1. **VDD 设备进入 Code 43**：一次运行时复测后 Parsec 适配器停止（`UnknownProblem`）。
   - 已用 `pnputil /restart-device` 恢复（用户授权）。
   - 处理：移除 `SetModeAndPosition` 里“每次都二次设置位置”的写法，避免额外模式切换扰动驱动；
     位置未生效改为接受实际坐标。
2. **体积**：`EnableCompressionInSingleFile=true` 后 167MB → 64.8MB；启动从 ~53ms 增至 ~330ms（每次进程启动一次）。
   - 影响：分发成本上升；后续可评估 trimming 或把 OCR 拆成可选组件。
3. **非默认 profile 位置仍不生效**：已从“挂载失败”降级为“可挂载但重叠”，文档已注明。
