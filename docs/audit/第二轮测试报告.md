## 0. 结论

第二轮用 PowerPoint 作为“最难 Office 场景”，同时验证修复后的契约质量。

- **成熟 MCP 项目**：修复前 60/100，仍不成立。协议与生命周期扎实，但图片通道不可用、画布型应用无语义、分发与 CI 仍是原型级。
- **OpenCode 调试 Windows 应用**：有条件成立。Word/Win32/UWP 可用；PPT 能出成品但路径昂贵；Chromium 仍阻断。
- **PPT 场景**：4 页中文 16:9，产物 11/11 结构校验通过；代价是 118 次工具调用、约 17 分钟、28 次截图。
- **修复后**：N1/N7/S3/S6/S7 等契约类缺陷已修；S1/S2/N2 仍为部分；分发、HTTP、CLI 并行仍阻塞。

## 3. 静态审查（07）

**结论**：协议层接近成熟；拖后腿的是感知广度、动作可验证性、分发生态。

- 静态分 64/100。
- 阻断级 0；P1 8 项；P2 10 项；P3 2 项。

## 4. 实际测试（08/09）

### 4.1 PPT 场景

4 页中文 16:9：

1. 标题页
2. 四点要点（含二级缩进）
3. 图文页（插入截图）
4. 3×4 表格页

产物：`artifacts/ppt/VScreenPilot-PPT-测评.pptx`，77,682 字节。

| 产物检查 | 结果 |
| --- | --- |
| 页数 4 / 16:9 | ✅ |
| 至少 1 张图 | ✅ |
| 表格 3×4、12 格有内容 | ✅ |
| 关键文本/无占位提示 | ✅ |
| 不越界/标题不重叠 | ✅ |

## 6. 改进与修复（10/11/12）

### 6.1 第一批：契约缺陷

| 项 | 修复 |
| --- | --- |
| N1 | `ImageContentBlock.FromBytes`（Data 是 base64 UTF-8 字节，不是原始 PNG） |
| N7 | `EvaluateCondition` 增加 `text`（UIA Name + TextPattern） |
| S3 | `document_ready` 三态 + reason；PPT/Excel 按标题；未建模返回 null |
| S6 | 默认 `abort`；`force/discard` 需 `allow_data_loss`；`E_DATA_LOSS_REQUIRED` |
| S7 | 检测图片/文件/HTML/RTF；auto 回退 SendInput；显式 clipboard 报 `E_CLIPBOARD_UNSAFE` |
| N4/N5/N6 | 空快照原因、死进程清理、dialogs root |
| 隐私 | 递归脱敏 tree/windows/foreground/annotations/OCR/focused_element |
| S2 | 三个高副作用工具改非只读；其余部分修复 |

### 6.2 第二批：感知与验证

| 项 | 修复 |
| --- | --- |
| 标注截图 | `snapshot{annotate:true}`：元素框 + 序号 + 网格 |
| 动作验证 | `click`/`press_keys`/`gesture` 返回 `observed{changed,ratio,region}` |
| OCR | `read_screen_text` / `click_text`；ASCII→en-US，中文→zh-Hans；OCR 可取消 |
| 文本定位 | `wait_for text`；PPT 画布靠 OCR 兜底 |
| 静态文本 | `Text/Image/Custom` 的 Name/Value/Text 非空即保留 |
| 取消 | 超时/客户端取消都把写锁与 CTS 交给 handler |
| 坐标降级 | `click{fallback_input:true}` |
| 多 profile | `VSP_FOCUS_LEASE=1` 输入租约（opt-in） |

### 6.3 第三批：工程化

- `resource_link` 内容块、`--cli env|snapshot|screen`。
- 48 个单测；CI 增加 PPT 步骤。
- `MetricsRegistry`（调用数/错误率/耗时/节点/OCR），随 `get_environment.metrics` 返回。
- `--doctor` 增加 `office.powerpoint`、`artifacts.writable`。
- 文档对齐、SECURITY/CONTRIBUTING/CHANGELOG/README.en。
- 单文件压缩：167MB → 64.8MB；启动约 330ms。
- `scripts/release.ps1`（只生成产物/哈希，不上传）。
