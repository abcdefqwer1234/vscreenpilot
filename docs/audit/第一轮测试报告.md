# 第一轮测试报告（Word / CCW）

> 汇总来源：`docs/audit/archive/00`–`06`
> 测试对象：VScreenPilot 0.1.0

## 0. 结论

第一轮回答了两个问题：

1. **是不是成熟 MCP 项目**：不是。静态 65/100，动态 66/100；协议与安全边界设计不错，但缺 CI/发布/单元测试，且存在两个会直接阻断使用的 P0。
2. **能不能让 OpenCode 调试 Windows 应用**：有条件可以。
   - Win32/WinForms/WPF：基本可用（UiTarget 10/14）。
   - Word：半自动 B 档（W-01～W-10 主流程通过，查找替换/另存为失败）。
   - CCW 12 / CefSharp / ag-grid：不可用，缺 CDP/IAccessible2/OCR 通道。

两个 P0：

- `mode=input` 缺少 `MOUSEEVENTF_VIRTUALDESK`，点击落不到虚拟屏。
- 连续全屏截图约 19–24 次后从 ~80ms 劣化到 ~1.9s，P95 2.3s。

重构后（run6）协议/契约/并发/GUI/回归/对话框全部转绿，但那一轮的 88 分是内部复评，口径与 65/66 不完全可比。

## 3. 静态审查结论（01）

**判定**：工程原型质量较高，但未达到成熟 MCP 标准。

主要优点：

- 虚拟屏隔离 + 焦点/光标护栏 + Job Object，设计在同类项目中少见。
- UIA + 像素/模板双通道，错误模型有 `code/stage/hint`。
- 中文文档完整，审计脚本可复现。

主要问题：

| 级别 | 问题 |
| --- | --- |
| P0 | `mode=input` 坐标缺 `MOUSEEVENTF_VIRTUALDESK` |
| P0 | CCW/CefSharp/ag-grid 缺可靠语义/点击通道 |
| P1 | UIA 线程安全与串行化不足；EOF/Dispose 可能被 UIA 卡住 |
| P1 | `get_ui_tree` 节点上限 2000 与 ref 容量 1024 不一致 |
| P1 | 显式 `baseline_frame_id` 不校验 x/y |
| P1 | 非法 `control_type` 静默使用默认值 |
| P1 | `release_environment` 等不到写租约仍清理 |
| P2 | outputSchema 泛化、无 title/idempotentHint |
| P2 | 无 CI、无单测、无 release/registry、npm 未发布 |
| P2 | IME/代理对/按键 down-up 未覆盖 |

静态评分：**约 65/100**。

## 4. 实际测试（02/03）

### 4.1 协议与安全

首轮逻辑用例：PRT 12/14、SEC 7/10。

| 项 | 结果 |
| --- | --- |
| 版本协商/未知版本回退 | ✅ |
| 未初始化调用/未知工具/非法 JSON | ✅ 正确错误码 |
| 重复请求 id | ❌ 未拒绝 |
| 取消/进度/fuzz/单实例/EOF | ✅ |
| 孤儿屏接管 | ⚠️ 实际接管，但 `adopted_orphan=false` 字段未赋值 |
| 越界/外来窗口/脚本开关/路径 | ✅ |
| 非法 `control_type` | ❌ 静默接受 |
| 跨区域 baseline | ❌ 未拒绝 |
| 系统键变体 | ⚠️ 部分变体返回 `E_NO_TARGET` 而非 `E_SYSTEM_KEY_BLOCKED` |

### 4.2 回归与 GUI

| 套件 | 结果 |
| --- | --- |
| UiTarget GUI | 10/14 |
| 回归 REG | 首轮 18 项中多项失败，run6 后 19/19 |

| 稳定性 | 50/50 会话循环通过；15 分钟 soak 在 UAC 安全桌面后失能 |

### 4.3 Word 场景

W-01～W-10 结果：

| 用例 | 结果 | 说明 |
| --- | --- | --- |
| W-01/02 新建与输入 | ✅ | 中文/英文/换行正确，回读一致 |
| W-03 格式 | ✅ | 加粗、标题样式，oracle 通过 |
| W-04 查找替换 | ❌ | 对话框是独立顶层窗口，UIA 不可达；输入会打到正文 |
| W-05 表格 | ✅ | 2×2 插入与填格，oracle 通过 |
| W-06 本地保存 | ✅ | 最小 docx 夹具，`Ctrl+S` 写本地 |
| W-07 另存为 | ❌ | 快捷键无响应；现代保存框拒绝完整路径；OneDrive 云占位 |
| W-08 受保护视图 | ⚠️ | `type_text` 返回 ok 但 `verified=false` |
| W-09 多应用隔离 | ✅ | Word/Notepad 互不串 |
| W-10 长文本 1949 字 | ✅ | 7651ms，61 块，`verified=true` |

**判定**：全自动否；半自动 B 档是。最大断点是模态对话框。

### 4.4 性能与稳定性

- 连续全屏截图第 19–24 次起 ~1.9s，P95 2.3s；同会话区域截图 ~32ms。
- 200 次全屏后 RSS 从 89MB 涨到 418MB（帧缓存 + LOH），释放后回落。
- 50 会话循环：挂屏 P95 3.6s、release P95 3.1s、截图 P99 2.0s。
- 15 分钟 soak：1388 次迭代，第 107 次起 UAC 安全桌面后 `capture_screen` 持续 `E_INTERNAL`、`type_text` 持续 `E_NO_INTERACTIVE_DESKTOP`，服务端未自愈。
- 句柄稳定，无持续泄漏。

### 4.5 CCW 12

安装与观测保留为附录 A；本轮未完成。结论：CefSharp/ag-grid 只有 `Custom` 节点，消息注入被拒绝，没有 CDP/IAccessible2/OCR，无法可靠编辑变量表。目标后来改为 Word，CCW 移出主线。

## 6. 改进与重构（04/05）

修复顺序：P0 → P1 → P2。

- P0-1：补 `MOUSEEVENTF_VIRTUALDESK`，DPI/虚拟桌面坐标。
- P0-2：像素路径复用 DC/DIB、去 `CAPTUREBLT`、默认 `scale=0.5`、大图落 artifact + 0.25× 预览。
- P0-3：Job Object 赋值检查、父进程/内容进程跟踪。
- P1：递归参数校验、错误目录、baseline 区域校验、`control_type` 白名单、ref 代际、release 租约、UIA 锁与退休队列。

重构方案覆盖 11 类协议/工具契约、10 项并发、8 项错误、10 项截图、11 项 UIA、10 项输入、9 项应用适配、8 项安全、10 项工程。

## 9. 与同类项目差距

- 强项：虚拟屏隔离、焦点/光标护栏、错误目录、ref 语义、审计脚本。
- 弱项：分发（PyPI/npm/Registry/签名）、HTTP 传输、CDP/OCR、英文生态、UIA 专用线程。
- 结论：从“能跑的原型”提升到“有契约的准生产工具”，但还不是成熟 MCP 项目。
